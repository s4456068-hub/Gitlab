## 0. Как устроен проект

- `src/main.py` — уже готовая точка входа: разбирает параметры командной строки, вызывает функции и печатает результат.
- `src/bank.py` — функции чтения, поиска, отображения и статистики. Они возвращают данные, а не печатают их.
- `datasets/bank.csv` — исходные 40 вопросов; `bank_dirty.csv` — банк с испорченными строками.
- `datasets/my_questions.csv` — собственные вопросы.
- `src/stress_tolerance_1.md` — личная заметка.
- `testing/test_bank.py`, `src/partner/lint.py`, `src/partner/check_bank.py` — проверки. Выданные файлы не изменяем.

Каждая строка CSV содержит семь полей, разделённых `;`. Заголовок:

```text
id;тема;уровень;тип;вопрос;варианты;ответ
```

Например:

```text
1;строки;1;один;Какая функция читает строку, которую ввёл человек?;print|input|int|len;2
```

Индекс | Ключ словаря | Тип | Значение
---|---|---|---
0 | id | int | 1
1 | topic | str | строки
2 | level | int | 1
3 | type | str | один
4 | text | str | текст вопроса
5 | options | list | ["print", "input", "int", "len"]
6 | answer | str | "2"

Индексы Python начинаются с нуля. Ответ остаётся строкой, поскольку может содержать несколько номеров или слова. Варианты разделяются `|`. В тексте CSV два символа `\n` обозначают настоящий перенос строки. В поле вопроса нельзя использовать `;`, иначе нарушится количество полей.

## 1. Сколько вопросов — load_bank

Цель: прочитать весь файл, собрать список словарей и вернуть его вместе с нулём. В задании 4 добавим обработку ошибок.

```python
def load_bank(path):
    questions = []
    with open(path, encoding="utf-8") as file:
        file.readline()
        for line in file:
            fields = line.rstrip("\n").split(";")
            options = []
            if fields[5]:
                options = fields[5].split("|")
            question = {
                "id": int(fields[0]),
                "topic": fields[1],
                "level": int(fields[2]),
                "type": fields[3],
                "text": fields[4].replace("\\n", "\n"),
                "options": options,
                "answer": fields[6]
            }
            questions.append(question)
    return questions, 0
```

- `def` объявляет функцию; `path` — путь к файлу, переданный при вызове.
- `questions = []` создаёт пустой список, который будет заполняться вопросами.
- `with open(...) as file` открывает файл в режиме чтения, UTF-8 поддерживает кириллицу. После выхода из блока файл закрывается автоматически.
- `readline()` читает первую строку. Мы не сохраняем её, потому что это заголовок.
- `for line in file` читает оставшиеся строки по очереди.
- `rstrip("\n")` убирает конечный перенос, не уничтожая остальные пробелы. `split(";")` превращает строку в список полей.
- `if fields[5]` проверяет, непустое ли поле вариантов. Если пустое, `options` остаётся пустым списком, а не списком с пустой строкой.
- `int()` преобразует текстовое число в целое. Словарь хранит значения по именованным ключам.
- `replace("\\n", "\n")` заменяет буквальную последовательность обратной косой черты и n на настоящий перенос.
- `append(question)` добавляет один словарь в общий список.
- `return questions, 0` возвращает два значения. В `main.py` они распаковываются через `questions, skipped = bank.load_bank(path)`.
- `return` находится вне цикла, иначе прочитался бы только первый вопрос.

## 2. Покажи вопрос — find_question и question_lines


```python
def find_question(questions, qid):
    """Найти в списке questions вопрос с номером qid (число).

    Возвращает словарь этого вопроса или None, если такого номера нет.
    """
    for question in questions:
        if question["id"] == qid:
            return question
    return None
```

`questions` — список словарей, `qid` — целое число (main.py уже преобразовал аргумент). Цикл проверяет ID каждого вопроса. `==` сравнивает значения, а `=` присваивает. При совпадении `return` сразу завершает функцию. Если совпадений нет, после цикла возвращается `None`. Номер вопроса не обязательно совпадает с индексом списка.

```python
def question_lines(question):
    """Строки, которые увидит человек на экзамене, — списком.

    Сначала строки текста вопроса, потом варианты: "1) ...", "2) ..." и так далее.
    Тема, уровень и ответ в эти строки не попадают.
    """
    lines = question["text"].split("\n")
    number = 1
    for option in question["options"]:
        lines.append(str(number) + ") " + option)
        number += 1
    return lines
```

`split("\n")` превращает многострочный текст в список отдельных строк. Нумерация вариантов начинается с 1. `str(number)` преобразует число в строку для склеивания с `") "` и вариантом. `number += 1` равносильно `number = number + 1`. Если вариантов нет, цикл не выполняется. Тема, ответ и уровень не выводятся. `main.py` сам вызывает `print()` для каждой строки результата.

```bash

python3 src/main.py datasets/bank.csv --show 23
python3 testing/test_bank.py 2
```

Первый вопрос показывает четыре варианта (print, input, int, len); второй — три строки текста с кодом и без вариантов. Несуществующий ID обрабатывает main.py.

## 3. Карта банка — count_levels и count_topics

```python
def count_levels(questions):
    """Сколько вопросов на каждом уровне.

    Возвращает словарь {уровень: число}, например {1: 10, 2: 9, ...}.
    """
    counts = {}
    for question in questions:
        level = question["level"]
        counts[level] = counts.get(level, 0) + 1
    return counts
```

```python
def count_topics(questions):
    """Сколько вопросов в каждой теме.

    Возвращает словарь {тема: число}, например {"строки": 12, ...}.
    """
    counts = {}
    for question in questions:
        topic = question["topic"]
        counts[topic] = counts.get(topic, 0) + 1
    return counts
```

`counts = {}` создаёт пустой словарь. `counts.get(level, 0)` берёт прежний счётчик или 0, если такого ключа пока нет. Прибавляем 1 и записываем обратно. Например, уровни 1, 2, 1 дают `{1: 2, 2: 1}`. Для тем алгоритм тот же. Отсутствующие уровни или темы main.py выводит как нули через `.get(..., 0)`.

```bash

```

## 4. Отбраковка — окончательная версия load_bank

Теперь заменяем реализацию первого задания. По документации достаточно трёх условий отбраковки: пустая строка, число полей не равно семи, уровень не является числом от 1 до 5.

```python
def load_bank(path):
    """Прочитать банк из файла по пути path.

    Возвращает два значения: список вопросов и число пропущенных строк.

    Первая строка файла — заголовок, это не вопрос.
    Каждый вопрос в списке — словарь с семью ключами:

        {"id": 23, "topic": "списки", "level": 2, "type": "короткий",
         "text": "Что напечатает код?\\nitems = [3, 1, 2]\\nprint(items[0])",
         "options": [], "answer": "3"}

    - "id" и "level" — числа, остальное — строки;
    - в "text" каждые два символа \\n из файла заменены настоящим переносом строки;
    - "options" — список вариантов; у вопросов типа «короткий» он пустой.

    Задание 1: верни все вопросы файла и 0.
    Задание 4: испорченные строки не попадают в список, их число — второе значение.

    Если файла нет, ошибку здесь не перехватывай: её перехватывает main.py.
    """
    questions = []
    skipped = 0
    with open(path, encoding="utf-8") as file:
        file.readline()
        for line in file:
            if not line.strip():
                skipped += 1
                continue
            fields = line.rstrip("\n").split(";")
            if len(fields) != 7:
                skipped += 1
                continue
            try:
                level = int(fields[2])
            except ValueError:
                skipped += 1
                continue
            if level not in [1, 2, 3, 4, 5]:
                skipped += 1
                continue
            options = []
            if fields[5]:
                options = fields[5].split("|")
            question = {
                "id": int(fields[0]),
                "topic": fields[1],
                "level": level,
                "type": fields[3],
                "text": fields[4].replace("\\n", "\n"),
                "options": options,
                "answer": fields[6]
            }
            questions.append(question)
    return questions, skipped
```

- `skipped = 0` — отдельный счётчик пропущенных записей.
- `not line.strip()` истинно для пустой строки или строки из пробельных символов.
- `len(fields) != 7` защищает от отсутствующих или лишних полей.
- `try` пробует преобразовать уровень. `except ValueError` перехватывает ошибку преобразования (например, `int("два")`).
- `level not in [1, 2, 3, 4, 5]` проверяет допустимый диапазон.
- При каждой ошибке увеличиваем `skipped` и выполняем `continue`: немедленно переходим к следующей строке. Поэтому одна строка считается только один раз.
- Корректные строки обрабатываются как в задании 1. Возвращаем фактический счётчик, а не 0.

Ограничение: эта реализация следует минимальному формату задания; произвольный неправильный ID может вызвать ValueError, поскольку дополнительные проверки формата здесь не требуются. Полную проверку выполняет check_bank.py. FileNotFoundError специально не перехватываем: это делает main.py.

```bash

python3 src/main.py datasets/bank_dirty.csv
python3 src/main.py datasets/bank_dirty.csv --stats
python3 testing/test_bank.py 4
```

## 5. Три собственных вопроса

Файл `datasets/my_questions.csv` начинается с оригинального заголовка. Тип `один` требует номер одного правильного варианта; `несколько` — номера через запятую без пробелов; `короткий` — пустые варианты и допустимые формы ответа через `|`. Для коротких ответов регистр и крайние пробелы не учитываются.

```text
id;тема;уровень;тип;вопрос;варианты;ответ
101;списки;1;один;Какой метод добавляет элемент в конец списка?;pop|append|lower|split;2
102;строки;2;короткий;Что вернёт len("кот")?;;3
103;числа;3;несколько;Какие условия проверяют что целое число x находится от 1 до 5 включительно?;x >= 1 and x <= 5|x > 1 and x < 5|not (x < 1 or x > 5)|x >= 1 or x <= 5;1,3
```

- 101: `append()` добавляет элемент в конец списка, поэтому ответ 2. Уровень 1, тема списки — пустая клетка.
- 102: `len("кот")` возвращает 3, поскольку в строке три символа. Уровень 2.
- 103: условия 1 и 3 включают обе границы; условие 2 исключает 1 и 5, условие 4 истинно для любого целого x. Уровень 3, тема числа — ещё одна пустая клетка.

## 7. Бонус — трудные вопросы

В конец CSV добавляются три записи уровня 4. В готовом файле они уже присутствуют.

```text
104;строки;4;короткий;Что напечатает код?\ns = "  Python  "\ns = s.strip().lower()\nprint(s.upper() + str(len(s)));;PYTHON6
105;списки;4;короткий;Что напечатает код?\nitems = [3, 1, 2]\nitems.append(items[0] + items[1])\nitems.pop()\nprint(sum(items));;6

```

104: `strip()` удаляет крайние пробелы, `lower()` переводит строку в нижний регистр, `upper()` — в верхний, `len()` возвращает 6, `str()` превращает длину в строку. Вывод `PYTHON6`.

106: после `int("12")` x равен 12. Первое условие истинно, x становится 15. Второе отдельное `if` тоже истинно, x становится 17. Вывод `17`.

Для каждого вопроса сначала предскажи результат, затем скопируй фрагмент кода в временный Python-файл и запусти его. В CSV реальные переносы записываются как `\n`; в обычном .py файле нужны настоящие переносы и отступы. Временные файлы не добавляй в Git.

## 8. Бонус — матрица банка

```python
def count_matrix(questions):
    """Задание 8 (дополнительное). Сколько вопросов каждой темы на каждом уровне.

    Возвращает словарь словарей {тема: {уровень: число}},
    например {"строки": {1: 4, 2: 2, ...}, ...}.
    """
    matrix = {}
    for topic in TOPICS:
        matrix[topic] = {}
        for level in [1, 2, 3, 4, 5]:
            matrix[topic][level] = 0
    for question in questions:
        topic = question["topic"]
        level = question["level"]
        matrix[topic][level] += 1
    return matrix
```

`TOPICS` объявлена в начале bank.py. Первый вложенный цикл создаёт четыре словаря по пять уровней, изначально с нулями. Второй цикл берёт тему и уровень каждого вопроса и увеличивает одну клетку. Например, `matrix["списки"][2] += 1` увеличивает количество вопросов про списки уровня 2. Результат — словарь словарей, а не список списков. Табуляцию и вывод формирует main.py.

```bash

```
